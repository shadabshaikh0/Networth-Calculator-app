# Recruiting testers — copy/paste messages

You need **12 testers** who **opt in and stay opted in for 14 days**. Replace
`<OPT-IN LINK>` with your Closed testing opt-in URL (Play Console → Closed
testing → Testers → copy link). Ask people to reply with the **Gmail they use on
their Android phone** so you can add them to the tester list (and, if they'll try
sync, as an OAuth test user).

## Tips
- **Android only** — iPhone users can't test a Play app.
- Send the link to **more than 12** people; not everyone follows through.
- If a tester wants to try **Google sync**, add their Gmail as a **test user** in
  Google Cloud → OAuth consent screen (the sensitive `drive.file` scope needs it
  until the app is OAuth-verified). Sync is optional; everything else works
  without signing in.
- Tester-swap communities (r/androiddev threads, dedicated tester groups) can
  fill gaps if you can't find 12 people.
